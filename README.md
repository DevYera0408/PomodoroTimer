# «Фокус»

Pomodoro-таймер с задачами и дневным прогрессом для школьников и студентов.

## Возможности

- **Pomodoro-таймер.** Режимы «Работа» — 25 минут и «Отдых» — 5 минут. Старт/пауза, сброс, переключение режимов, обратный отсчёт.
- **Учёт минут в реальном времени.** Во время работы минуты фокуса начисляются по ходу сессии (по одной за каждую полную минуту).
- **Задачи.** Добавление по `Enter` или кнопкой, отметка выполнения, удаление. Прогресс за сегодня — доля выполненных среди незавершённых и завершённых сегодня задач.
- **Серия дней (streak).** День засчитывается при ≥ 60 минутах фокуса. Хранится история по дням, текущая серия и рекорд.
- **Достижения.** Вехи серии (10, 20, 30, 40, 50 дней, далее каждые 10): полученные значки, заблокированные с подсказкой «осталось N дней» и тост при достижении вехи.
- **Темы.** Тёмная и светлая, строгая чёрно-белая палитра, шрифты IBM Plex.
- **Без бэкенда и аккаунтов.** Все данные хранятся в `localStorage` браузера. Бэкенд только спроектирован (`docs/backend-foundation.md`), но не реализован.

## Запуск

```bash
pnpm install
pnpm dev
```

Dev-сервер запускается на `http://localhost:8443` (порт задаётся в `vite.config.ts`, переопределяется переменной окружения `PORT`).

Сборка и проверка типов:

```bash
pnpm build      # production-сборка в dist/
npx tsc --noEmit  # проверка типов
```

Дополнительно в `package.json` есть скрипт `pnpm preview` (предпросмотр собранной версии) и `pnpm format` (oxfmt).

Бэкенд запускается отдельно, из своей папки (порт 3000 по умолчанию, переопределяется `PORT`):

```bash
cd server && pnpm install && pnpm dev   # http://localhost:3000/api/v1/health
```

Команды приведены по `package.json` и инструкциям проекта; при подготовке этого README они не запускались.

## Структура проекта

- `src/App.tsx` — всё приложение: типы, хелперы, иконки и компонент `App`.
- `src/index.css` — Tailwind и кастомные классы/анимации.
- `src/main.tsx` — точка входа.
- `index.html` — HTML-оболочка, подключение шрифтов IBM Plex.
- `docs/` — память проекта (`docs/ai-memory/`) и проектная документация.
- `docs/backend-foundation.md` — проект бэкенда и контракт API v1; этап 1 (каркас + health) реализован.
- `server/` — отдельный пакет бэкенда (Fastify + TypeScript strict); пока только `GET /api/v1/health`.

## Данные в localStorage

| Ключ | Что хранится |
| --- | --- |
| `focus-tasks` | Массив задач `{ id, text, completed, completedDate? }` |
| `focus-stats` | Статистика текущего дня `{ date, focusMinutes }`; сбрасывается при смене дня |
| `focus-days` | История минут по дням `{ "YYYY-MM-DD": минуты }` |
| `focus-streak` | Серия и рекорд `{ current, best }` |
| `focus-theme` | Тема: `'dark'` или `'light'` |

Данные локальные: очистка `localStorage` сбрасывает задачи, статистику, историю, серию и настройку темы. Состояние таймера не сохраняется.

## Известное состояние и ограничения

- Часть изменений (серия дней, обновление стилей) может ещё не быть закоммичена — актуальное состояние смотрите в `git status` / `docs/ai-memory/CURRENT_STATE.md`.
- Рантайм-проверки в браузере выполняет пользователь; автотестов в проекте нет.
- `setInterval` может дрейфовать в фоновой вкладке; таймер не восстановится после перезагрузки страницы.
- Шрифты IBM Plex подключаются с Google Fonts, поэтому при первом запуске нужна сеть.
- `PROJECT_AUDIT.md` — история технического аудита и исправленных дефектов.

## Документы для контрибьюторов и AI-ассистентов

- `AGENTS.md` — правила работы с репозиторием: стек, ограничения, команды, конвенции.
- `docs/ai-memory/PROJECT.md` — краткое описание проекта, стека и модели данных.
- `docs/ai-memory/CURRENT_STATE.md` — что сделано, что осталось и не проверено, следующий шаг.
- `docs/ai-memory/DECISIONS.md` и `docs/ai-memory/SESSION_LOG.md` — принятые решения и журнал сессий.
