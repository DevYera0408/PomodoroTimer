# Решения

## D-001 — Внешний вид: строгая чёрно-белая тема (2026-10-17)
- Контекст: интерфейс выглядел как сгенерированный ИИ (градиенты, индиго/синие цвета, крупные скругления, тени, шрифт Inter по умолчанию).
- Решение: палитра только чёрный/белый; светлая тема — фон `#FAF8F5`, текст/акцент `#1A1A1A`; тёмная — фон `#000000`, текст/акцент `#FFFFFF`. Активные элементы: светлая — чёрная заливка + белый текст, тёмная — белая заливка + чёрный текст.
- Форма: радиус ≤ 4px, вместо теней — границы 1px; крупные кнопки (`min-height: 3.25rem`).
- Шрифты: `IBM Plex Sans` (интерфейс), `IBM Plex Mono` (цифры таймера).
- Причины: убрать «шаблонный» вид, повысить читаемость и контраст, единый вид в обеих темах.
- Следствие: шрифты тянутся через Google Fonts `<link>`; при отсутствии сети работает фолбэк `system-ui`/`ui-monospace`.
